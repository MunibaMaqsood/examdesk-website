# ExamDesk

A website for conducting exams online. Build timed papers, let candidates sit them from any device, and get results instantly.

**Live site:** https://munibamaqsood.github.io/examdesk-website/

## Features
- Multiple choice, true or false and short answer questions
- Automatic countdown timer with auto-submit
- Instant marking with pass or fail outcome
- Question palette and flag-for-review
- Answer review and results record

## Built with
HTML, CSS and JavaScript (no frameworks). Hosted on GitHub Pages.
